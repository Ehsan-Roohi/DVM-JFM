# Bird DSMC1S dependency

The shock campaigns use G. A. Bird's `DSMC1S` Fortran normal-shock program as a third-party dependency. This repository supplies the campaign modifications as a unified patch, the author-written `paper_diagnostics.f90`, configurations, compact profiles and analysis code. It does **not** distribute the complete original or modified `.for` program: no explicit redistribution grant was found in the inspected local source header. This observation is not a determination that redistribution is prohibited; permission and authoritative distribution terms must be established separately.

The locally preserved original is `DSMC1S_original.for`, SHA-256 `159f0f8c8aeb14ba1e99acf5fed07f74700934d5cdaad0e7953f40bfde4fb2ee`. Its header identifies `PROGRAM DSMC1S`, describes a one-dimensional normal-shock simulation and SI units. The local campaign manifest records the source hashes, but does not establish an authoritative download URL or license. Obtain the matching original from its legitimate distributor and check its hash before applying the patch; an original with a different hash is not silently interchangeable.

Both included campaign patches are identical. The resulting archived modified program has SHA-256 `30fedcc04641694a43a8727d523f9a96b18a70b49346fbd8f4f4f193a0da5c8e`; this hash covers the original Windows bytes. Patch application may normalise line endings, so compare normalised text as well as the recorded raw-file hash. Apply in a private working directory containing the matched original, e.g. `patch -p0 < bird_dsmc_m2_high_particles_20261009.patch`. This audit generated the diff but did not compile or execute the resulting solver.

The modifications add configuration/restart/block diagnostics and increase particle capacity; the author-written diagnostics module is located beside the campaign manifest in `research/revision_runs/bird_dsmc_m2_high_particles_20261009/`. A Fortran compiler and the module must be available to build the program. A verified portable compiler command and compiler version have not been recovered in this audit, and the archived preflight checks also refer to operating wrappers not included in this compact publication subset. Therefore this dependency is **not yet a self-contained one-command reproduction workflow**.

Keep attribution to Bird and inspect distribution terms before further redistribution. Do not interpret a repository-level license for author-owned material as a license for third-party original source. See `PATCH_PROVENANCE.json` and each campaign's `manifest.json` for source signatures and run configuration.
